================================================================
 خطة مشروع التخرج: كشف الهجمات الشبكية باستخدام Scapy (NetGuard-IDS)
 طالب: Basil | التاريخ: 2026-10-21
================================================================

1) الهدف
--------
بناء أداة دفاعية تكشف هجمات الشبكة (MITM عبر ARP Spoofing، Deauth،
Evil Twin، ومخاطر Sniffing) وتُظهر تنبيهًا مبكرًا بدلًا من تنفيذ
أي هجوم. المشروع تعليمي وقانوني: يشرح الهجوم نظريًا، ويحمي عمليًا.

2) الفكرة الأساسية
------------------
- الجزء النظري: شرح أنواع الهجمات وكيف تحدث (راجع docs/attack_theory.md).
- الجزء العملي: أداة بـ Python/Scapy تقوم بـ:
  * Sniffing: التقاط الحزم وتحليلها.
  * كشف ARP Spoofing: تعارض تعيينات IP↔MAC → تنبيه MITM.
  * كشف Deauth: إطارات فصل متكررة خلال نافذة زمنية قصيرة.
  * كشف Evil Twin: نفس SSID من BSSIDs مختلفة.
  * توثيق الأدلة: ملف تنبيهات JSONL + ملف PCAP للحزم المشبوهة.
- النتيجة: تنبيه "احتمال هجوم" بدلًا من تنفيذ الهجوم نفسه.

3) البرمجيات والبيئة
--------------------
- Windows (جهاز العرض): Python 3.10+، مكتبة scapy، Npcap للالتقاط
  الحقيقي من كرت الشبكة، colorama سلوك الألوان.
- مختبر افتراضي: VirtualBox/VMware بثلاثة أجهزة (ضحية + مهاجم +
  مراقب) على شبكة داخلية فقط بدون إنترنت.
- لجزء الواي فاي (Deauth/Evil Twin): يُفضل Kali Linux أو Linux مع
  محول USB يدعم وضع المراقبة (monitor mode).

4) هيكل المشروع
---------------
main.py                        نقطة التشغيل (sniff/simulate/selftest/list-ifaces)
config.json                    العتبات والإعدادات
ids_tool/
  alert.py..alerts.py          نظام التنبيهات (شاشة + JSONL)
  evidence.py                  الأدلة (PCAP + JSON)
  sniffer.py                   محرك الالتقاط والتوزيع على الكاشفات
  simulator.py                 محاكاة آمنة 100% (حزم في الذاكرة فقط)
  detectors/arp_spoofing.py    كاشف ARP Spoofing → MITM
  detectors/deauth.py          كاشف Deauth/Disassociation
  detectors/evil_twin.py       كاشف Evil Twin (+تغير التشفير)
tests/lab_spoof_sim.py         مولد مرور مختبري معزول (بقفل تأكيد ملكية)
docs/attack_theory.md          الشرح النظري للهجمات (لملف التقرير)
logs/                          مخرجات الجلسات (تنبيهات + أدلة)

5) خطة التنفيذ الزمنية
----------------------
الأسبوع 1: أساسيات الشبكات (IP/MAC/ARP/OSI) + تشغيل selftest.
الأسبوع 2: كاشف ARP Spoofing + مراجعة محاكاة ARP.
الأسبوع 3: كاشف Deauth + Evil Twin على بيئة واي فاي مراقَبة.
الأسبوع 4: المختبر الافتراضي + اختبار lab_spoof_sim + توثيق لقطات.
الأسبوع 5: كتابة التقرير + تجهيز العرض أمام اللجنة.

6) خطوات التشغيل
----------------
- تثبيت:  python -m pip install -r requirements.txt
- اختبار: python main.py selftest
- محاكاة: python main.py simulate
- الواجهات: python main.py list-ifaces
- الالتقاط الحقيقي: python main.py sniff --mode arp --iface "Wi-Fi"
   (Windows: افتح الطرفية بصلاحيات Administrator + ثبّت Npcap)
- مختبر حقيقي: tests/lab_spoof_sim.py داخل شبكة VirtualBox داخلية.

7) طريقة العرض أمام اللجنة
--------------------------
1. شرح الهجوم برسم (MITM / Deauth / Evil Twin).
2. تشغيل python main.py simulate → عرض التنبيهات لحظيًا.
3. تشغيل الالتقاط الحقيقي داخل الشبكة + مراقبة الأدلة (JSONL/PCAP).
4. الخاتمة: قيمة التنبيه المبكر + ربط مستقبلي مع IDS/IPS أو جدار ناري.

8) الحدود القانونية (مهم للعروض والتقارير)
------------------------------------------
- لا تنفذ الأداة أي هجوم؛ التغطية للكشف فقط.
- الاختبار على شبكات خاصة أو بإذن مكتوب من مالك الشبكة.
- اختبارات الواي فاي داخل بيئة معزولة (VirtualBox/هوت-سبوت شخصي).
- سكربت المختبر يقفل تلقائيًا دون تأكيد صريح بالملكية.

9) تطوير مستقبلي
-----------------
- واجهة GUI/ويب + إشعارات.
- تكامل مع جدار حماية أو أمر حجب (IP/MAC) عند التنبيه.
- دعم منحنى تقسيم يعتمد التعلم الآلي لتقليل الإنذارات الكاذبة.
